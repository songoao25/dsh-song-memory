# Support

Need help with dsh-song-memory? Here's where to go:

## Where to ask

- **Bug reports & feature requests**: open an
  [issue](https://github.com/songoao25/dsh-song-memory/issues).
- **Questions & discussion**: use the repository's
  [Discussions](https://github.com/songoao25/dsh-song-memory/discussions) tab.
- **Security vulnerabilities**: follow the process in
  [SECURITY.md](./SECURITY.md) — do not open a public issue.

## Before asking

1. Check the [README](./README.md) — the 5-minute quick start covers install
   and first-time verification.
2. Check the [docs](./docs/zh-CN/README.md) for detailed guides
   (getting-started, providers, operations, troubleshooting).
3. Search existing issues for the same problem.

## Version support

We support the latest release and the current `main` branch. When reporting a
bug, include the version you are running (visible in the 运行状态 / Status page).
