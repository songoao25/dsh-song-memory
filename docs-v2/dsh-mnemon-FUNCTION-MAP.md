# dsh-mnemon 功能全貌梳理（v2.0 界面重构基础）

> 来源：工程师子 Agent ea8b2daa 只读分析 /tmp/package（dsh-mnemon@0.2.9）
> 用途：产品定义「保留全部功能、用苹果 HIG 理念简化界面」的基础

## 功能模块共 14 个

| # | 模块 | 一句话用途 | 主要操作 | 复杂度 |
|---|---|---|---|---|
| 1 | 状态 status | 看引擎/存储/连接是否正常 | 查看、刷新 | 低 |
| 2 | 运行时 runtime | 每轮注入的紧凑热记忆（USER.md/MEMORY.md 投影） | 查看、添加 | 低 |
| 3 | 档案 documents | 项目文档（设计/复盘/交接）搜索与查看 | 搜索、查看全文 | 中 |
| 4 | 记忆体 spaces | 长期记忆空间（每个项目一个，隔离） | 创建、激活/停用、归档、删除 | **高** |
| 5 | 图谱 graph | 实体与关系的可视化（节点/边） | 查看、检查器 | **高** |
| 6 | 检索 search | 跨记忆空间的召回搜索 | 搜索、筛选 | 中 |
| 7 | 实体 entities | 记忆中的实体列表 | 查看、筛选 | 中 |
| 8 | 沉淀 remember | 记忆写入（LLM 判定） | 查看写入记录、确认 | 中 |
| 9 | 沉淀策略 strategy | 自动写入策略（何时写/写什么） | 配置规则 | **高** |
| 10 | 内容浏览 content | 按分类浏览记忆内容 | 浏览、筛选 | 低 |
| 11 | 备份恢复 backup | 备份/恢复记忆数据 | 备份、恢复、导入导出 | 中 |
| 12 | 配置 config | 插件整体设置（Provider/显示模式等） | 配置 | **高** |
| 13 | 对话内 UI | 对话页「存入记忆」「本回合记忆」按钮 | 存入、查看 | 低（高频） |
| 14 | 版本/Headless | 引擎版本检查、命令行 | 检查、更新 | 低 |

## 信息架构现状

- 对话区 2 个高频入口（存入记忆 / 本回合记忆）
- 设置页 1 个大卡片（7 个分区）
- 工作台一级导航 4 项 + 记忆体二级标签 4 项
- 最深 4~5 层（页面 → 弹窗 → 检查器 → 全文预览）
- 两种显示模式：sidebar（侧边栏工作台）/ buildin（对话区标签页）

## 最常用 5 个功能（普通用户）

1. 对话内「存入记忆」
2. 本回合记忆查看
3. 检索（召回）
4. 记忆体开关注（激活/停用）
5. 运行时添加

## 最该简化的 3 个模块

1. **记忆体创建 + 策略 + Provider 配置**——同一批难懂字段分散两处重复
2. **备份导入**——组件勾选 + 合并/覆盖，概念复杂
3. **图谱 + 实体**——节点/边/检查器概念抽象

## 简化草案（功能全保留前提）

- **默认简单、高级折叠**：高频操作平铺，高级配置收进"高级"折叠
- **术语全白话**：记忆体→记忆仓库；沉淀→存入记忆；召回→检索；Provider/存储域→统一本地/云端
- **一级导航 4 项**：记忆 / 小抄 / 档案 / 状态
- 15 条术语对照表（见工程师报告）
